# Usage

[简体中文](Usage-zh-CN)

### Install

Download `Copia-0.0.1.zip` from [GitHub Releases](https://github.com/D0n9X1n/copia/releases), unzip it and move `Copia.app` to `/Applications`. Copia requires macOS 27.

This build is signed with an Apple Development certificate but not notarized, so macOS blocks the first launch. Open **System Settings → Privacy & Security**, find the message about Copia and click **Open Anyway**.

On first launch, onboarding asks for two permissions:

| Permission | Why | Without it |
|---|---|---|
| Accessibility | Copia sends ⌘V to the app you were using | Picking a card only copies it; press ⌘V yourself |
| Clipboard access (Always Allow) | Copia reads the clipboard to keep history | macOS may ask each time Copia reads the clipboard |

### Copy and paste

- **⌘C** anywhere: the item is added to the front of your history. Copying something again moves it to the front.
- **⌘Y**: open or close the strip on the display under the pointer. Change this shortcut in Settings → Shortcuts.

In the strip:

| Key | Action |
|---|---|
| ← / → | Select the previous or next card |
| ↩ or double-click | Paste into the previous app |
| ⇧↩ | Paste as plain text |
| ⌘1 – ⌘9 | Paste that card (⇧ for plain text) |
| ⌘C | Copy the card without pasting |
| ⌫ | Delete the card (only when the search is empty) |
| ⌘Z | Undo the delete |
| Type | Search |
| ⎋ | Clear the search, then close |

Right-click a card for Paste, Paste as Plain Text, Copy and Delete. Hold ⌘ to see the ⌘1–9 badges.

### What is kept

Text, rich text, images, links, files and colors. Images get a thumbnail, links load their title and image once and keep them, and colors (`#RRGGBB`) show a swatch. Deleting a card also deletes its saved files.

History is kept for **1 Month** by default (1 Day, 1 Week, 1 Month, 1 Year or Forever in Settings → General). **Erase History** removes everything after you confirm.

Data lives in `~/Library/Application Support/Copia/`: `copia.sqlite` plus `blobs/`, `thumbs/` and `trash/`.

### Privacy

- Copia never reads clipboard content that apps mark as concealed or transient (`org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`, and 1Password's and other password managers' markers).
- Copies made while an ignored app was in front are skipped. Passwords and 1Password are ignored by default; edit the list in Settings → Privacy.
- **Pause Capture** (⌘T or the menu bar) stops capture. Anything copied while paused is never stored.
- Nothing leaves your Mac except the one-time request a link makes to load its own preview.

### Known limits

- macOS has no clipboard-change notification, so Copia checks every 0.5 s. If two copies happen within the same half second, only the second is kept.
- When more than one app was in front between two checks, the card's source is shown as unknown.
- The ⌘V that Copia sends uses the QWERTY V key position.
