# Usage

[简体中文](Usage-zh-CN)

### Install

From [GitHub Releases](https://github.com/D0n9X1n/copia/releases), download the app for your Mac's chip:

- Apple silicon: `Copia-<version>-arm64.zip`
- Intel: `Copia-<version>-x86_64.zip`

Not sure which? Apple menu → **About This Mac** shows **Chip** on Apple silicon and **Processor** on Intel. Both require macOS 26 or later. Compare the ZIP’s SHA-256 with its `.sha256` file before extracting, then unzip it and move `Copia.app` to `/Applications`. See **Verification** in the notes for that release for actual runs on Intel hardware and macOS 26.

This build is signed with an Apple Development certificate but not notarized, so macOS blocks the first launch. Open **System Settings → Privacy & Security**, find the message about Copia and click **Open Anyway**.

Allow clipboard access so Copia can save new copies. Accessibility is not a prerequisite: picking a card **only writes the clipboard**. Copia does not send keystrokes; press ⌘V yourself in the destination app.

**Settings → About** shows the running app’s version. **Check for Updates** compares it with Copia’s latest stable GitHub release. If a newer version is available, choose **View Release** to review it. Copia does not download or install updates for you.

### Copy and paste

- **⌘C** anywhere: the item appears below your pins. Copying something again moves it to the front of its pinned or unpinned group.
- **⌘Y**: open or close the strip on the display under the pointer. Change this shortcut in Settings → Shortcuts.

The strip opens in **Results**. Press a card to select it immediately; double-click copies the pointed card, not a previously selected card. Return or ⌘1–9 copies and closes; add Shift for plain text. Press ⌘V in the destination when ready.

| Key in Results | Action |
|---|---|
| ← / → | Select the previous or next card |
| ⌘C | Copy the primary card without closing |
| ⌘A | Select the matches visible now; later matches do not join this selection |
| ⌫ · ⌘Z | Delete selected cards as a batch · undo the whole batch |
| ⌘P | Pin or unpin the primary card; pinned cards sort first and do not age out |
| Type or click Search | Edit the query |
| ⎋ | Clear the search, then close |

In **Search**, arrows, Delete, ⌘A, ⌘C and Undo operate on text, not cards. Input methods keep control while composing. Finish composition, then press Tab or ↓ to return to Results without clearing the filter. Right-click actions target the pointed card. Hold ⌘ to see numbered shortcuts.

### What is kept

Text, rich text, images, links, files and colors. Images get a thumbnail, links load their title and image once and keep them, and colors (`#RRGGBB`) show a swatch. Deleting a card removes it from history and keeps a short-lived undo snapshot. If redundant files cannot be removed, a cleanup warning stays visible while Copia retries; Erase History never claims all files are gone when cleanup fails.

History is kept for **1 Month** by default (1 Day, 1 Week, 1 Month, 1 Year or Forever in Settings → General). Pins are exempt from age-based retention, not explicit deletion. **Erase History** removes everything after you confirm.

Data lives in `~/Library/Application Support/Copia/`: `copia.sqlite` plus `blobs/`, `thumbs/` and `trash/`.

### Privacy

- Copia never reads clipboard content that apps mark as concealed or transient (`org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`, and 1Password's and other password managers' markers).
- Copies made while an ignored app was in front are skipped. Passwords and 1Password are ignored by default; edit the list in Settings → Privacy.
- **Pause Capture** (menu bar; no default shortcut) stops capture. Anything copied while paused is never stored.
- Links make a one-time request for their own preview. A manual update check contacts GitHub, which receives your IP address and the generic `Copia` user agent. Copia does not send your running version, clipboard contents, or history in that request.

### Known limits

- macOS has no clipboard-change notification, so Copia checks every 0.5 s. If two copies happen within the same half second, only the second is kept.
- When more than one app was in front between two checks, the card's source is shown as unknown.
- The menu bar icon is visible by default. If hidden in Settings, use the strip’s gear or reopen Copia to get back to Settings.
