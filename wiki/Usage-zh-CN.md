# 用法

[English](Usage)

### 安装

从 [GitHub Releases](https://github.com/D0n9X1n/copia/releases) 下载 `Copia-0.0.1.zip`，解压后把 `Copia.app` 移到 `/Applications`。Copia 需要 macOS 27。

此版本使用 Apple Development 证书签名，但未经公证，因此 macOS 会阻止首次启动。打开 **系统设置 → 隐私与安全性**，找到关于 Copia 的提示，点按 **仍要打开**。

首次启动时，引导页面会请求两项权限：

| 权限 | 用途 | 没有它时 |
|---|---|---|
| 辅助功能 | Copia 向你刚才使用的应用发送 ⌘V | 选中卡片只会复制，需要你自己按 ⌘V |
| 剪贴板访问（始终允许） | Copia 读取剪贴板以保存历史 | macOS 可能会在每次读取剪贴板时询问 |

### 复制与粘贴

- 在任意位置按 **⌘C**：内容会加入历史的最前面。再次复制同一内容会把它移到最前面。
- **⌘Y**：在指针所在的显示器上打开或关闭卡片栏。可在 设置 → 快捷键 中更改。

在卡片栏中：

| 按键 | 操作 |
|---|---|
| ← / → | 选择上一张或下一张卡片 |
| ↩ 或双击 | 粘贴到之前的应用 |
| ⇧↩ | 以纯文本粘贴 |
| ⌘1 – ⌘9 | 粘贴对应卡片（加 ⇧ 为纯文本） |
| ⌘C | 只复制卡片，不粘贴 |
| ⌫ | 删除卡片（仅在搜索为空时） |
| ⌘Z | 撤销删除 |
| 直接输入 | 搜索 |
| ⎋ | 先清空搜索，再关闭 |

右键点按卡片可选择 粘贴、以纯文本粘贴、复制 和 删除。按住 ⌘ 可显示 ⌘1–9 标记。

### 保存的内容

文本、富文本、图片、链接、文件和颜色。图片会生成缩略图；链接只加载一次标题和图片并保存；颜色（`#RRGGBB`）显示为色块。删除卡片时会同时删除它保存的文件。

历史默认保留 **1 个月**（在 设置 → 通用 中可选 1 天、1 周、1 个月、1 年或永久）。**清除历史** 在你确认后删除全部内容。

数据位于 `~/Library/Application Support/Copia/`：`copia.sqlite` 以及 `blobs/`、`thumbs/` 和 `trash/`。

### 隐私

- Copia 从不读取被应用标记为隐藏或临时的剪贴板内容（`org.nspasteboard.ConcealedType`、`TransientType`、`AutoGeneratedType`，以及 1Password 等密码管理器的标记）。
- 在被忽略的应用位于前台时进行的复制会被跳过。默认忽略“密码”和 1Password；可在 设置 → 隐私 中编辑。
- **暂停捕获**（⌘T 或菜单栏）会停止捕获。暂停期间复制的内容永远不会被保存。
- 除了链接为加载自身预览而发出的一次请求外，没有任何数据离开你的 Mac。

### 已知限制

- macOS 没有剪贴板变化通知，因此 Copia 每 0.5 秒检查一次。如果在同一个半秒内复制两次，只会保留第二次。
- 如果在两次检查之间有多个应用位于前台，卡片的来源会显示为未知。
- Copia 发送的 ⌘V 使用 QWERTY 键盘上 V 键的位置。
