# 用法

[English](Usage)

### 安装

从 [GitHub Releases](https://github.com/D0n9X1n/copia/releases) 下载与 Mac 芯片对应的应用：

- Apple 芯片：`Copia-<版本号>-arm64.zip`
- Intel：`Copia-<版本号>-x86_64.zip`

不确定？打开苹果菜单 → **关于本机**：显示 **芯片** 为 Apple 芯片，显示 **处理器** 为 Intel。两者均要求 macOS 26 或更高版本。解压前请用对应的 `.sha256` 文件核对 ZIP 的 SHA-256，然后解压并把 `Copia.app` 移到 `/Applications`。该版本是否经过 Intel 实机或 macOS 26 测试，请看发布说明中的 **Verification**。

此版本使用 Apple Development 证书签名，但未经公证，因此 macOS 会阻止首次启动。打开 **系统设置 → 隐私与安全性**，找到关于 Copia 的提示，点按 **仍要打开**。

允许访问剪贴板后，Copia 才能保存新复制的内容。不需要辅助功能权限：选取卡片**只会写入剪贴板**，不会向其他应用发送按键。请在目标应用中手动按 ⌘V。

在 **设置 → 关于（About）** 中可以查看当前运行的版本。点按 **检查更新（Check for Updates）**，即可与 GitHub 上 Copia 的最新稳定版比较。如有新版本，点按 **查看发布页（View Release）** 了解详情。Copia 不会自动下载或安装更新。

### 复制与粘贴

- 在任意位置按 **⌘C**：新卡片排在置顶项之后。再次复制同一内容会把它移到所在组（置顶或未置顶）的最前面。
- **⌘Y**：在指针所在的显示器上打开或关闭卡片栏。可在 设置 → 快捷键 中更改。

卡片栏默认处于**结果**模式，选中的是剪贴板当前内容对应的卡片。剪贴板跟随选中项：用 ← 和 → 移动选中项（输入搜索时也可以），停下后即复制该卡片；按住方向键时，剪贴板最终停在你停下的那张卡片上。浏览不会覆盖其他应用刚复制、Copia 尚未看到的内容。清空搜索后，选中项会回到剪贴板当前对应的卡片。

单击卡片会选中并复制它，卡片栏保持打开。双击、回车或 ⌘1–9 会复制并关闭；加按 Shift 则复制纯文本。按 ⌘Y 或点回原来的应用也会关闭，并保留选中的卡片。**Esc** 表示取消：用方向键浏览后按 Esc，会恢复浏览前的剪贴板（上一次已写入剪贴板的选定卡片，或打开时的卡片）并关闭。Esc 不会覆盖你在此期间从其他应用复制的内容；剪贴板改变时 Copia 尚未保存的内容也无法恢复（例如隐藏的密码，或打开前一瞬间复制的内容）；提示会说明能否恢复。浏览时，搜索栏旁会弹出 **Copied** 提示，并附 **esc** 键帽，表示按下即可恢复之前的剪贴板，或说明无法恢复。搜索框有内容时只显示 **Copied**，因为 Esc 会先清空搜索。单击、⌘C 或菜单中的“拷贝”改变剪贴板时，也会显示 **Copied** 约 2 秒；Esc 不会撤销这类选择。切到目标应用后手动按 ⌘V。

| 结果模式按键 | 操作 |
|---|---|
| ← / → | 选择上一张或下一张卡片，剪贴板随之更新（搜索模式中同样有效） |
| ⌘← ⌘→ · Home End | 跳到第一张或最后一张卡片，剪贴板随之更新（Home 和 End 在搜索模式中同样有效） |
| ⌘C | 复制主选卡片，不关闭卡片栏 |
| ⌘A | 选中此刻符合筛选条件的结果；之后出现的匹配项不会加入 |
| ⌫ · ⌘Z | 批量删除所选卡片 · 撤销整批删除 |
| ⌘P | 置顶或取消置顶主选卡片；置顶项排在前面，不因到期而删除 |
| 图钉按钮 | 置顶或取消置顶该卡片，但不复制；悬停和选中的卡片上会显示，已置顶的卡片始终显示 |
| 输入或点按搜索框 | 编辑搜索词 |
| ⎋ | 先清空搜索；否则关闭并恢复之前的剪贴板 |

在**搜索**模式中，← →、Home 和 End 仍会浏览匹配的卡片，搜索词保持不变；加 ⌘ ⌥ ⇧ 的方向键、删除、⌘A、⌘C 和撤销只操作文字，不影响卡片。输入法组词时优先处理按键。结束组词后按 Tab 或 ↓ 返回结果，筛选条件不变。右键菜单作用于指针下的卡片。按住 ⌘ 查看数字快捷键。

### 保存的内容

文本、富文本、图片、链接、文件和颜色。图片会生成缩略图；链接只加载一次标题和图片并保存；颜色（`#RRGGBB`）显示为色块。删除卡片会将其移出历史并保留短暂的撤销快照。如果冗余文件无法移除，Copia 会持续显示清理警告并重试；清理失败时，“清除历史”不会宣称所有文件已经删除。

历史默认保留 **1 个月**（在 设置 → 通用 中可选 1 天、1 周、1 个月、1 年或永久）。置顶项不会随保留期到期，但可以手动删除。**清除历史** 在你确认后删除全部内容。

数据位于 `~/Library/Application Support/Copia/`：`copia.sqlite` 以及 `blobs/`、`thumbs/` 和 `trash/`。

### 隐私

- Copia 从不读取被应用标记为隐藏或临时的剪贴板内容（`org.nspasteboard.ConcealedType`、`TransientType`、`AutoGeneratedType`，以及 1Password 等密码管理器的标记）。
- 在被忽略的应用位于前台时进行的复制会被跳过。默认忽略“密码”和 1Password；可在 设置 → 隐私 中编辑。
- **暂停捕获**（通过菜单栏，默认未绑定快捷键）会停止捕获。暂停期间复制的内容永远不会被保存。
- 链接会请求一次自身的预览。仅当你手动检查更新时，Copia 才会联系 GitHub；GitHub 会收到你的 IP 地址和通用的 `Copia` 用户代理标识。此请求不包含当前版本、剪贴板内容或历史记录。

### 已知限制

- macOS 没有剪贴板变化通知，因此 Copia 每 0.5 秒检查一次。如果在同一个半秒内复制两次，只会保留第二次。
- 如果在两次检查之间有多个应用位于前台，卡片的来源会显示为未知。
- 菜单栏图标默认显示。如果在设置中隐藏了图标，可从卡片栏的齿轮或通过重新打开 Copia 返回设置。
